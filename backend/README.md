# Proyecto Frontend y Backend con Docker

## Descripción
Este proyecto consiste en una aplicación web desarrollada con frontend y backend utilizando tecnologías como HTML, CSS, JavaScript, Node.js y Express.js. Además, se implementó Docker para la creación y comunicación entre contenedores.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Docker
- Docker Compose
- GitHub
